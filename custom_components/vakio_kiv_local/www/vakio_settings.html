Запуск локального интерфейса

Браузер не разрешает этому файлу читать ответы устройства напрямую. В файле уже есть небольшой локальный сервер: он передаёт запросы между интерфейсом и устройством.

  1. Нужен Python 3. Никакие дополнительные пакеты не требуются.
  2. Выполните команду ниже в терминале. Если файл перемещён, укажите его новый путь.
  3. Откроется этот интерфейс. Держите терминал открытым; для завершения нажмите Ctrl+C.

Сервер слушает только этот компьютер. Пароли не записываются в файл и не сохраняются в браузере. Передача устройству идёт по HTTP, как в его штатном интерфейсе.

Диагностика и ограничения

Загрузка: GET / → чтение полей штатной формы. Сохранение: POST /newdata с JSON, как в оригинале. Отправляются все известные настройки; если время точки доступа неизвестно, по умолчанию отправляются 15 минут. После ответа 200 значения считываются повторно. Подключение к MQTT и применение настроек оцениваются только по тому, что сообщает прошивка. Подтвердить сохранность после перезагрузки можно только отдельной проверкой после перезапуска устройства.

При тайм-ауте сохранения интерфейс автоматически перечитывает настройки и сравнивает их с отправленными. Сам запрос сохранения не повторяется: устройство могло его принять. Пароли и содержимое запросов в журнал не попадают.

Работает с форматом web-интерфейса VAKIO KivSmart, проверенным 27 октября 2026 года. При несовместимой прошивке сохранение блокируется.
