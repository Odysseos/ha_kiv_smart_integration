Настройки прошивки Vakio

Для работы с устройством скачайте страницу и программу запуска на компьютер, подключённый к его локальной сети. Устанавливать Python или запускать программу внутри Home Assistant не требуется.

  1. Сохраните оба файла в одну папку:
    • Скачать страницу vakio_settings.html
    • Скачать программу запуска vakio_settings.py
  2. Установите Python 3, если его ещё нет. Дополнительные пакеты не нужны.
  3. Откройте терминал в папке с файлами и выполните python3 vakio_settings.py. В Windows можно использовать py -3 vakio_settings.py.
  4. Браузер откроет страницу на http://127.0.0.1:…/. Если он не открылся, скопируйте адрес из терминала.
  5. Введите IP устройства и нажмите «Подключиться и загрузить». Загрузка только читает настройки. Для записи внесите изменения и нажмите «Сохранить изменения».

Держите терминал открытым во время работы. Для остановки нажмите Ctrl+C.

Прошивка не сообщает время отключения точки доступа. Страница подставляет 15 минут — значение по умолчанию, подтверждённое техподдержкой Vakio. Оно отправляется вместе с остальными настройками.

Это отдельный инструмент настройки прошивки. Параметры подключения MQTT-клиента HA и настройки записи Vakio KIV Local он не меняет.
