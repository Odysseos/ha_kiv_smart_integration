# Настройки прошивки через локальную страницу

[Установка интеграции](integration.md) · [Ручной вариант](../manual/README.md) · [Главная](../README.md)

Инструмент позволяет читать и изменять Wi-Fi, точку доступа, MQTT-сервер,
базовый MQTT-топик и общие настройки KIV Smart без замены прошивки.
Он поставляется вместе с Vakio KIV Local и может использоваться отдельно
от Home Assistant, в том числе при ручном варианте интеграции.

## Почему штатная страница не сохраняет настройки в локальной сети

В исследованной штатной странице прошивки адрес сохранения жёстко задан:

```javascript
fetch("http://192.168.0.1/newdata", {
  method: "POST",
  body: JSON.stringify(Object.fromEntries(formData))
})
```

Даже если прибор уже подключён к домашнему Wi-Fi и страница открыта по его
новому адресу, запрос уходит на `192.168.0.1`. Этот адрес может быть связан
с первоначальной настройкой через точку доступа, но он не является адресом
прибора после подключения к вашей сети. Ошибка затрагивает все разделы
настроек, включая выбор собственного MQTT-брокера.

В штатном коде также отсутствует обработчик `.catch()`, а уведомление
показывается только при ответе HTTP 200. В результате пользователь нажимает
«Сохранить настройки» и не получает ни сохранения, ни объяснения ошибки.
Это дефекты web-интерфейса производителя, а не MQTT-брокера или HA.

Корректное исправление в самой странице прошивки — относительный адрес
`fetch("/newdata", ...)`. При этом запрос отправляется тому устройству,
с которого открыта страница. Поставляемый здесь инструмент не перепрошивает
прибор: он обходит ошибку, явно отправляя запрос на выбранный IP.

## Получение файлов

После установки или обновления интеграции через HACS перезапустите HA.
В браузере откройте адрес своего HA, добавив путь:

```text
/vakio_kiv_local/settings.html
```

Например, если HA открывается по `http://homeassistant.local:8123`, адрес:

```text
http://homeassistant.local:8123/vakio_kiv_local/settings.html
```

На странице скачайте **оба файла в одну папку**:

- `vakio_settings.html` — интерфейс и встроенный локальный сервер;
- `vakio_settings.py` — программа запуска этого сервера.

Если интеграция ещё не установлена, возьмите файлы непосредственно из
репозитория: [страница HTML](../custom_components/vakio_kiv_local/www/vakio_settings.html)
и [программа запуска](../custom_components/vakio_kiv_local/www/vakio_settings.py).
На GitHub используйте скачивание исходного файла, а не сохранение страницы
просмотра кода.

## Запуск на компьютере

Нужен Python 3 на компьютере, который имеет сетевой доступ к прибору.
Дополнительные пакеты, установка Python в HA и постоянно работающий сервис
не требуются.

1. Откройте терминал в папке с двумя скачанными файлами.
2. На Linux или macOS выполните:

   ```bash
   python3 vakio_settings.py
   ```

   На Windows:

   ```powershell
   py -3 vakio_settings.py
   ```

3. Откроется браузер с адресом `http://127.0.0.1:…/`. Если браузер не открылся,
   скопируйте полный адрес из терминала. Порт выбирается автоматически.
4. Оставьте терминал открытым. Для завершения работы нажмите **Ctrl+C**.

Можно использовать только HTML: откройте его как локальный файл в браузере
и выполните показанную в верхней части страницы команду Python. Результат
тот же — открывается страница локального сервера.

Страница, скачанная из HA, запускается на компьютере, а не в HA.
Нельзя открыть HTML в панели HA и напрямую обратиться из него к прибору:
браузер ограничивает запросы между разными источниками, а HTTPS-страница
HA дополнительно ограничивает обращения к HTTP-устройствам.
Локальный сервер выполняет запросы к прибору вне этих браузерных ограничений.

## Подключение и сохранение

1. В поле **«IPv4-адрес устройства»** укажите фактический IP прибора в вашей
   сети. Предзаполненный адрес в форме — пример; замените его на свой.
   IP можно посмотреть в списке клиентов роутера.
2. Нажмите **«Подключиться и загрузить»**. Это только чтение: HTTP GET `/`.
3. Проверьте загруженные поля. Выберите нужную вкладку, например **«MQTT»**,
   затем **«Свой сервер»**. Укажите адрес брокера без схемы и порта,
   порт отдельным полем, логин, пароль и базовый топик.
4. Нажмите **«Сохранить изменения»**. Запрос HTTP POST `/newdata` отправится
   на IP, с которого были загружены настройки. Изменение IP требует новой
   загрузки перед сохранением.
5. Страница повторно читает настройки и сравнивает их с отправленными.
   Читайте итоговое сообщение: ответ HTTP 200 сам по себе ещё не доказывает
   применение всех значений.

При изменении Wi-Fi прибор может отключиться и получить новый IP.
Повторное чтение по прежнему адресу тогда завершится ошибкой: найдите новый
IP на роутере и подключитесь заново.

При тайм-ауте страница не повторяет POST автоматически: прибор мог уже
принять настройки. Вместо повтора выполняется чтение. Если результат
не подтверждён, сначала используйте **«Проверить / перечитать»**.

Статус MQTT берётся из ответа прошивки. Подключение к брокеру и сохранность
параметров после перезапуска следует проверить отдельно.

## Время отключения точки доступа

Прошивка не сообщает странице текущее значение `APTIME`. По сведениям
техподдержки Vakio, значение по умолчанию — **15 минут**. Поэтому при
отсутствии значения страница намеренно подставляет 15 минут (`APTIME=0`).
Это корректная подстановка заводского значения, а не результат чтения
текущего состояния.

Сохранение передаёт все известные настройки, включая это значение, даже
если вы изменили только MQTT. Если ранее выбрали другое время отключения
точки доступа, выберите нужное значение во вкладке **«Точка доступа»**
перед сохранением. Подтвердить `APTIME` повторным чтением невозможно,
пока прошивка его не сообщает; интерфейс явно об этом предупреждает.

## Границы инструмента

- Сервер слушает только `127.0.0.1` на вашем компьютере и принимает запросы
  к частным IPv4-адресам на HTTP-порту 80.
- Пароли не записываются инструментом на диск, в хранилище браузера или
  в журнал операций. Они присутствуют в форме и передаются устройству по
  HTTP, как в штатном интерфейсе.
- Сохранение блокируется, если в странице прибора отсутствуют обязательные
  поля ожидаемого формата. Это проверка структуры, а не гарантия
  совместимости со всеми версиями прошивки.
- Сброс к заводским настройкам требует отдельного подтверждения. Он может
  удалить Wi-Fi и MQTT-настройки и лишить прибор доступа по текущему IP.
- Настройки MQTT-клиента HA и записи Vakio KIV Local не изменяются.
  Если меняете базовый топик прибора, учтите, что существующая запись
  интеграции продолжит использовать прежний префикс.
