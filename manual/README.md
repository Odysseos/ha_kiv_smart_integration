# Ручная установка через blueprint

Этот вариант работает без установки custom component. [Общий подход](../docs/approach.md)
и [ограничения MQTT](../docs/mqtt.md) общие с интеграцией.

## Установка

Требуются HA 2025.10.0+, настроенная интеграция MQTT и прибор с MQTT-префиксом.
Проверенный прибор: KIV Smart, штатная прошивка 1.1.8 ESP32.

Из **этого каталога manual** скопируйте в каталог HA с configuration.yaml:

| Файл в manual | Путь в HA |
| --- | --- |
| `blueprints/automation/vakio_cover.yaml` | `blueprints/automation/vakio_cover.yaml` |
| `includes/vakio_cover.yaml` | `includes/vakio_cover.yaml` |

Добавьте прямо в существующий configuration.yaml:

```yaml
homeassistant:
  packages:
    vakio_cover: !include includes/vakio_cover.yaml
```

Не создавайте второй ключ homeassistant или packages. Добавьте строку
в существующий словарь. Фрагмент также находится в
[configuration_vakio_additions.yaml](configuration_vakio_additions.yaml).
Пакет содержит несколько секций, поэтому подключать его как automation нельзя.

В [includes/vakio_cover.yaml](includes/vakio_cover.yaml) настройте экземпляр:

| Параметр | Пример | Значение |
| --- | --- | --- |
| topic_prefix | vakio_kiv | Префикс из настроек физического прибора |
| id_prefix | vakio_kiv_cover | Постоянный уникальный ID этого экземпляра |
| device_name | Vakio KIV — приточный клапан | Название прибора |
| memory_entity | input_text.vakio_kiv_cover_memory | Его собственный помощник |
| boot_report_window | 3 | Защитная задержка отчётов, секунд |

Если YaHA не установлен, удалите из пакета всю секцию yandex_smart_home,
оставив input_text и automation. Проверьте конфигурацию HA и перезапустите HA.
Discovery должен использовать префикс homeassistant и сообщение рождения
homeassistant/status → online: эти пути в blueprint фиксированы.

## Начальная цель и восстановление

**При пустой или некорректной памяти заслонка сама открывается** в ручном
режиме: декабрь–февраль — Малое; март/ноябрь — Среднее;
апрель/октябрь — Большое; май–сентябрь — Полное. Используется часовой пояс HA.
Это только начальная установка, не ежемесячная автоматизация.
Затем восстанавливается последняя сохранённая цель при старте HA и auth прибора.
Помощник должен иметь max: 255 и не должен иметь initial.

## Сущности

Для примера создаются cover.vakio_kiv_cover,
select.vakio_kiv_cover_selection, sensor.vakio_kiv_cover_temperature,
sensor.vakio_kiv_cover_humidity. Память — input_text.vakio_kiv_cover_memory.
Названия списка «Открытие заслонки»: Нет, Малое, Среднее, Большое, Полное,
Авто. Любое ручное положение выходит из Авто. Ползунок округляет ненулевое
значение до ближайшей из четырёх ступеней.

Температура и влажность в blueprint приводятся к целому числу;
неверный payload превращается в 0. Нативная интеграция, в отличие от него,
сохраняет дробные значения и отбрасывает некорректные измерения.

## Несколько приборов

Настройки экземпляров и их помощников находятся в **одном includes/vakio_cover.yaml**.
Для нового прибора добавьте собственный input_text с max: 255 без initial,
новый элемент automation и, при YaHA, новую запись entity_config.
Задайте уникальные topic_prefix, id_prefix, id автоматизации и memory_entity.
В копии YaHA замените все ссылки cover/select/sensor на сущности нового прибора.
Не дублируйте корневые ключи секций. Один помощник для двух приборов запрещён.
Подключение пакета в configuration.yaml остаётся единственным.

## YaHA

Пример уже включён в пакет. Включение выбирает Полное, выключение — Нет,
программы low/medium/high/max/auto соответствуют Малое/Среднее/Большое/Полное/Авто.
Датчики включены в одну карточку ventilation, числовая функция open отключена.

**entity_config не включает передачу автоматически.** При YAML-фильтрации
добавьте cover.vakio_* в существующий filter.include_entity_globs,
сохранив правила остальных устройств. Фрагмент:
[examples/yaha_filter.yaml](examples/yaha_filter.yaml). В настройках YaHA
выберите YAML-фильтрацию. При иных ID разрешите фактический cover явно.
Обновите список устройств провайдера в «Дом с Алисой».

Подробности и типичные ошибки: [настройка YaHA](../docs/yaha.md).
